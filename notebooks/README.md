# Notebooks

This folder previously contained large exported scripts from Kaggle.

**Current status (May 2026):**

- The original large Kaggle export files (`anomaly-detection-scenario1.py` and `anomaly-detection-scenario2.py`) have been removed as they were redundant copies of exploratory work and are **not used** by the core pipeline in `src/`.
- The active entry point `run_src.py` has been moved to the repository root for better discoverability.

The core pipeline is now executed via `python run_src.py` from the root.
